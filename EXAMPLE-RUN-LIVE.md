# EXAMPLE-RUN-LIVE.md -- the kit's author running the kit

EXAMPLE-RUN.md is invented, on purpose: it shows the SHAPE of a run without
claiming anyone walked it. This file is the other kind. It is the journal of
a real run, on the repository that ships this kit, appended as the run goes
and copied here unedited -- gate reports with their evidence, the decisions
behind them, and the defects the run found in the kit itself.

It is a builder's record, not a certificate. It says what was faced and what
was caught; it says nothing about whether any application is secure.

2026-09-03 — DECISION (reconstructed): OAuth with a JWT bearer, and no
  passwords at all
context: the audience is professionals on LinkedIn and the product wants
  a visible profile; storing passwords would add a breach surface for no
  product gain. Reconstructed from `backend/src/auth/` and the `User`

  fails closed: a token that fails verification raises Unauthorized
